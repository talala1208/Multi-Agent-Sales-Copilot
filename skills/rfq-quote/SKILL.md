# 处理询价请求

按以下步骤顺序执行。维护待办列表，方便 Jane 查看进度。

## 1. 阅读请求

- 请 **inbox-manager** 找到请求并完整阅读。提取：询价人、公司/邮箱，以及具体需求（哪些类型/曲目、各要多少）。

## 2. 确认客户

- 请 **chinook-analyst** 按邮箱（必要时辅以姓名）查找客户。
- **若系统中没有该客户**，请 chinook-analyst 用 `add_customer` 添加。系统会自动暂停等待 Jane 审批 — 分析师应直接调用，不要在文字里先询问。审批通过后继续。

## 3. 获取价格

- 请 **chinook-analyst** 提供所需单价：
  - 「某类型 N 首曲目」：该类型可用曲目数量及标准 `UnitPrice`（曲目通常 $0.99；需核实，不要假设）。
  - 「畅销曲目」：请分析师按销量提供排行榜。
- 从数据库获取真实数字；不要猜测价格。

## 4. 精确计算报价

- 用 **代码解释器** 做算术 — 数量 × 单价、行折扣和总额。不要手算金额。
- 合理的默认批量折扣：订单 50 首及以上享 10% 折扣。在报价中明确写出折扣。

## 5. 审核

- 将明细行和总额发给 **quote-reviewer**。起草前先按审核意见修正。

## 6. 起草回复

- 以 Jane 口吻写简短友好的回复：致谢，列出每行（描述、数量、单价、行小计），写出折扣和总额，并说明后续步骤。
- 请 **inbox-manager** 将草稿保存给发件人，传入主题和完整正文。系统会自动暂停，供 Jane 在保存前批准或编辑措辞 — 不要先在消息里口头要许可。草稿从不自动发送。

## 7. 记录

- 向 `/outputs/quotes_ledger.md` 追加一行：日期、客户、项目摘要、总额和草稿 ID。若文件不存在，先创建并写入表头行。

## 完成

告知 Jane 草稿已在草稿文件夹中，并汇总报价总额。
